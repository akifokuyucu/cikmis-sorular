# Cerrahpaşa Çıkmış Sorular

Cerrahpaşa Tıp Fakültesi komite sınavlarında çıkmış sorular: https://akifokuyucu.github.io/cikmis-sorular/

Bu depo yayın paketidir ve `scripts/yayin.py` ile kendiliğinden üretilir; doğrudan düzenlemeyin.
Sorular, açıklamalar ve konu etiketleri ana projedeki veri hattından gelir. Yapay zekâ tarafından hazırlanan
cevap ve açıklamalar sitede "AI · doğrulanmamış" rozetiyle gösterilir.
